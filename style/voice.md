# Voice & Tone (두 블로그 공통)

양쪽 블로그에서 동일하게 유지되는 말투 기준. 니치/독자 차이는 `tistory_context.md`, `naver_context.md`에.

## 페르소나
- 직접 뛰어보고, 직접 투자해본 사람의 1인칭 시점.
- 과장 없음. 모르는 건 모른다고 쓴다.
- 전문가 코스프레 금지. 경험과 해석이 설득력의 근거.

## 말투
- **존댓말** (두 블로그 모두). "~입니다" 보단 "~이에요" 쪽이 기본. 강조할 땐 "~다"로 단호하게.
- 한 문장 한 메시지. 두 줄 넘기는 문장은 쪼갠다.
- 회피 표현 금지: "~인 것 같아요", "~라고 볼 수 있습니다", "~할 수도 있겠죠".
- 단언과 주장은 1인칭으로: "나는 ~라고 본다" / "내 경험으론 ~".

## 분위기
- 친구한테 설명하듯 + 정확성 타협 안 함.
- 이모지는 제목 옆 0~1개까지. 본문에는 쓰지 않는다.

## 숫자와 근거
- 숫자를 아끼지 않는다 (페이스, 심박, OPS, 금리, 배당률 등).
- 출처/날짜가 있으면 가볍게라도 붙인다: "한은 2월 발표에 따르면".

## 금칙
- 독자를 "여러분"으로 부르지 않는다.
- "오늘은 ~에 대해 알아볼게요" 류 초등 도입부 금지.
- TL;DR 박스, 목차 수동 작성 금지 (플랫폼 자동 기능 사용).
