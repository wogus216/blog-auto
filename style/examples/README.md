# Examples

여기에 **과거에 내가 직접 쓰고 만족했던 글**을 `.md`로 넣어둔다.
polish 단계에서 few-shot 예시로 주입된다.

## 규칙
- 파일명: `good_01.md`, `good_02.md` ... (숫자는 품질 순서 아님, 그냥 식별자)
- 프론트매터 없이 **순수 본문만**. 실제 글 톤이 그대로 학습 샘플이 됨.
- 최소 2~3개는 넣어야 스타일이 안정됨. 0개면 AI 기본톤으로 돌아감.
- 너무 길면 잘라도 됨. 2,000자 이상이면 대표 섹션만.

## 주의
- 여기 넣은 글은 프롬프트에 포함되어 API로 전송된다. 민감한 내용이면 빼거나 마스킹.
