# 찐주부J 톤 네이버 글 템플릿 (ekdud0706 패턴 추출)

5개 글 분석으로 추출한 찐주부J 작가 표준 패턴. 새 글 작성 시 이 골격대로.

## 📐 제목 공식 (★★★★★ 99% 일관)

```
[충격적 숫자/혜택 의문문]? [핵심 키워드] [정보] [동작 동사]
```

예시 (실제):
- "원금 4배? 청년내일저축계좌 혜택, 1440만원 조건 떴다"
- "청년도약계좌 해지 고민? 12% 청년미래적금 갈아타기 답 나왔다"
- "퇴직연금 수익률 64% 차이... DC형 DB형 어디서 갈렸나"

규칙:
- 의문문 또는 ?... 후 핵심 키워드
- 숫자(금액·%·배수) 반드시 포함
- 마무리는 "떴다 / 답 나왔다 / 갈렸나 / 다 받는 건 아니다" 식 동작 동사

## 📐 본문 골격 (4단계)

```
[1] 도입 (1~2 단락)
  - 배경 1줄
  - "정리해 봤다" 또는 "한번 들여다봤다" 마무리
  - [이미지 슬롯 #1: 히어로]

[2] 핵심 한줄 요약
  - "수익률 X%, 원금 Y배, 월 Z만원으로 ..." 식 임팩트
  - [인용박스] 한줄 요약

[3] "[키워드]는?" H3 섹션 × 3~5개
  - "[키워드] 혜택은?"
  - "[키워드] 조건/자격은?"
  - "[키워드] 신청 방법은?"
  - "[키워드] 주의사항은?"
  - 각 섹션마다 이미지 1~2장 + 표 또는 인용박스

[4] 마무리
  - "그러니 ~한 사람은 신청 가능 ..." 핵심 정리
  - [이미지 슬롯: 마무리]
  - 본인 다른 글 외부 링크 카드 5~10개
```

## 📐 시각 요소 비율 (찐주부J 표준)

| 요소 | 권장 개수 |
|---|---|
| 이미지 | **7~8장** |
| 표 | **3~4개** |
| 인용 박스 | **3~4개** |
| 외부 링크 카드 | 7~14개 (본인 다른 글) |
| 스티커 | 0 (안 씀) |
| 구분선 | 0 (안 씀, 표/인용으로 분리) |

## 📐 톤 앤 매너

- 구어체+분석 혼합: "~분위기라", "~답 나왔다", "정리해 봤다"
- 1~2인칭 사용: "**내가** 매월", "**우리는**"
- 한 문장 짧게 (15~30자), 줄바꿈 많이
- 숫자·금액·% 항상 굵게/색상 강조
- "%" "배" "만원" 단위 강조

## 📐 표 사용 케이스

- ✅ 자격 조건 (가구원수별 소득 등)
- ✅ 금액 비교 (이전 vs 현재, 트랙별)
- ✅ 일정 (단계별)
- ✅ 비교 (혜택 A vs B)

## 📐 인용 박스 사용 케이스

- 💡 꿀팁 / 핵심 한줄
- ⚠️ 주의사항
- 📌 한줄 요약
