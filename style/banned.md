# Banned Expressions

AI가 기본값으로 쓰기 쉬운 표현들. polish 단계에서 제거 대상.

## 상투구
- "결론적으로", "마무리하자면", "요약하자면"
- "~인 것 같아요", "~라고 볼 수 있습니다"
- "오늘은 ~에 대해 알아보겠습니다"
- "여러분", "독자분들"
- "흥미로운", "놀랍게도", "사실"

## 과장
- "혁신적인", "획기적인", "최고의", "완벽한"
- "반드시", "절대"  (실제로 반드시/절대가 아닌 맥락에서)

## 군더더기
- "~라는 점에서", "~에 대해서 말하자면"
- "한편", "또한" (문장 시작용으로 남발 금지)

## 구조
- TL;DR 박스
- "목차"를 본문에 직접 작성 (플랫폼 기능 사용)
- 이모지 나열 (🚀 ✨ 🎯 같은 AI 특유 패턴)
