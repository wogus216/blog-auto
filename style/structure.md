# Structure

블로그 글의 기본 뼈대. outline 프롬프트가 이 구조를 참조한다.

## 표준 구조
1. **훅 (2~3문장)** — 이 글을 왜 읽어야 하는지. 구체적인 상황/문제.
2. **문제 정의** — 무엇이 어려운지, 어떤 맥락인지.
3. **본론** — 단계별 또는 개념 단위. 각 섹션은 H2.
   - 코드가 있으면 바로 붙이고, 코드 위아래 1~2문장으로 의도/주의점 설명.
4. **흔한 실수 / 함정** (선택) — 내가 겪은 것만.
5. **정리** — bullet 3~5줄. "결론적으로" 같은 군더더기 없이.

## 길이
- 기본 1,500~2,500자.
- 코드 중심 글은 더 짧아도 됨. 설명 중심이면 길어져도 OK.

## 금지
- TL;DR 박스
- "안녕하세요 여러분"류 인사
- "오늘은 ~를 알아보겠습니다" 같은 초등학생 도입부
- 목차 (플랫폼이 자동 생성함)

## AdSense 광고 자연 배치 (CPC 모드일 때 우선 고려)

자동 광고가 끼어들기 좋은 구조를 만들면 CPC 단가가 올라간다. 기본 구조에 다음을 덧붙인다.

### H2 개수와 분포
- **H2를 5~7개로 쪼개라**. H2 ↔ H2 경계가 자동 광고 핵심 슬롯.
- 각 H2 본문은 **최소 200자, 평균 350~500자**. 너무 짧으면 광고 슬롯 안 생기고, 너무 길면 이탈 ↑.
- H2 아래 H3는 1~3개까지. 너무 많으면 광고 위치 분산.

### 도입 hook 직후 슬롯
- hook(2~3문장) 직후에 **빈 줄 + 첫 H2 진입**. 이 사이에 자동 광고가 들어가는데 단가가 가장 높다.
- hook 안에 결론을 미리 던지지 말 것. 결론은 첫 H2 또는 마지막에.

### 본문 중간 시각 요소
- **표(table)·이미지·인용블록**은 광고 자동 배치의 트리거. 비교형 글은 표를 1~2개 꼭 넣기.
- 단, 표 안에 광고가 들어가지 않도록 표 위아래 빈 줄 확보.

### 결론 전 여백
- 마지막 "정리" 섹션 위에 **빈 줄 2줄**. 자동 광고가 결론 직전에 자연스럽게 끼어든다.

### 길이 조정 (CPC 모드)
- 기본 1,500~2,500자 → CPC 모드는 **2,500~4,000자**까지 허용. 광고 슬롯을 더 만들기 위함.
- 단, 분량을 위한 채우기 금지. 비교 표·체크리스트·FAQ 같은 정보 밀도 높은 섹션으로 늘릴 것.

## Blogger 심층 본글 종착지 규약 (blogger / blogger_stocks / blogger_money 공통 — 필수)

> 2026-06-10 티스토리 GA4 28일 분석에서 나온 결론을 Blogger에 이식한다. 모든 Blogger 글은 아래 규약을 **반드시** 따른다. 위 "표준 구조"는 기본 뼈대, 여기부터는 Blogger 종착지 전용 강제 규칙.

### 왜 Blogger가 "종착지"인가 (어제 CSV 인사이트)
- **양산 롱테일 무덤**: 티스토리 786글 중 88%가 10뷰 미만, 상위 6%가 트래픽 51%. → 양산 중단, **깊이 한 방**으로 전환. Blogger는 양산처가 아니라 **심층 본글의 종착지**.
- **트래픽-단가 미스매치**: 티스토리는 앵커광고 금지([[feedback_tistory_ad_policy_anchor_ban]])라 RPM 천장이 낮음. **고단가(부동산·금융·여행) 본글은 Blogger에 두고, 티스토리·네이버는 요약+링크로 트래픽을 Blogger로 펌프**한다.
- **챔피언 패턴**: 단일 글(대한항공 성수기)이 전체 수익 18% 생산. 공통점 = **시즌성 + 고단가 니치 + 긴 참여(93초)**. Blogger 본글은 이 템플릿을 복제한다.
- **GEO 피벗**: LLM이 인용할 수 있는 **팩트 리드 + 1차 출처 + FAQ 구조화**가 Blogger 본글의 핵심 자산. 검색 + AI 인용 둘 다 잡는다.

### 분량·구조 (심층 본글)
- **최소 5,000자, 권장 6,000~10,000자.** 짧은 요약·관점글로 끝내지 말 것. 깊이가 체류시간·SEO·AI 인용의 핵심.
- 구조: ① 후크(공감/문제제기 1~2줄) + 팩트 리드 도입 → ② **핵심 요약 박스(HTML)** → ③ 본문 H2 6~10개 → ④ **비교표·체크리스트** 1개 이상 → ⑤ **FAQ 3~5개**(GEO·JSON-LD용) → ⑥ 정리 + **다음 행동 CTA**.
- 숫자·고유명사(단지명·티커·분양가·날짜)를 본문에 살려 둘 것. 추상 표현 금지.

### 이미지 (필수 — 최소 2장, 권장 3~4장)
- **텍스트 전용 글 발행 금지.** `{{broker:<key>}}` 토큰 한 줄이면 발행 시 이미지+출처가 자동 치환된다(`inject_broker_assets`, 플랫폼 무관 동작 — 티스토리와 동일).
- 제품/공식 컷 = `scripts/capture_page.py` / 분위기·실사 = `scripts/unsplash_fetch.py`(무료) / 수치·비교 = **데이터 카드 토큰**(아래) / 공고문 = PDF 캡처([[project_pdf_screenshot_embed]]).
- 배치: 헤더 1장 + 본문 H2 사이 분산 2~3장.
- **제품 실물컷 캡처**: `capture_page.py`는 기본 레티나 2배(`--scale 2`)·쿠키/팝업 자동 닫기. 셀렉터를 모를 땐 `--auto-product`로 페이지 내 최대 제품 이미지를 자동 추출(봇차단 사이트는 폴백). 화질↑·UI잡동사니↓.

### 데이터 시각화 카드 (수치·비교·일정은 표 대신 카드 토큰)
- 매번 inline HTML을 손으로 짜지 말 것. 본문에 `:::타입 제목` … `:::` 펜스 토큰만 넣으면 발행 시 인포그래픽 HTML로 자동 치환된다(`inject_viz_cards`). 각 줄은 `|`로 필드 구분.
- **티스토리·Blogger 전용**(HTML). 네이버는 `strip_viz_cards`가 자동으로 텍스트 불릿 폴백 처리하므로 같은 토큰을 그대로 써도 안전.
- 타입: `schedule`(날짜·시간 그리드) / `stat`(KPI 하이라이트 박스) / `compare`(2~3열 비교, 마지막 필드 `best`면 추천 강조) / `rank`(TOP 순위, 메달색 자동) / `spec`(라벨-값 스펙).
- 예:
  ```
  :::compare VOO vs KODEX 레버리지
  VOO (미국) | 운용보수 0.03% / S&P500 추종 / 장기적립 | best
  KODEX 레버리지 | 보수 0.64% / 코스피 2배 / 단기용
  :::
  ```
- 색·여백은 `html_enhance` 디자인 토큰과 공유 → 글 전체 톤 일관. 비교형 글의 "표 1~2개" 규약을 카드로 충족 가능.

### Blogger 고유 제약 (어기면 발행 실패/중복)
- **본문 H1 금지.** frontmatter `title`이 H1로 렌더되므로 본문은 `## `(H2)부터 시작. 위계 H1>H2>H3>H4 ([[feedback_blogger_no_h1_in_body]]).
- **태그(label) 11개 이하.** 12개 이상이면 Blogger API가 400으로 거부. frontmatter tags는 11개 이내 ([[feedback_blogger_label_cap]]).
- **자동광고 ON 전제**로 구조를 짤 것(본문 분산 슬롯). money 블로그는 본문 광고 코드 지원됨([[project_adsense_ad_coverage_gap_20260603]]).

### GEO / 후크·CTA
- **FAQ 섹션 필수** + 1차 출처(청약홈·국세청·한국은행·SEC·공식 IR) 명시 인용 → LLM 인용 종착지. JSON-LD(`scripts/inject_jsonld.py`)와 정합.
- **돈 되는 글 3요소**([[feedback_money_post_structure]]): 제목 후크 + 도입부 당김 + 본문 다음행동 CTA. **단 YMYL(부동산·금융)은 과장·낚시·단정 금지** — 후크는 사실 범위 안에서 톤만([[feedback_adsense_policy_safety]]).

### 챔피언 / 내부링크 허브
- 시즌성+고단가 본글(분양 임박·성수기 마일리지·실적 시즌·연말정산 등)을 **우선 복제**.
- 본글 하단에 관련 본글 2~3개를 묶어 **내부링크 허브**를 만든다. 티스토리·네이버 요약글이 이 허브로 트래픽을 흘려보낸다.
