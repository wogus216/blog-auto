# Structure

블로그 글의 기본 뼈대. outline 프롬프트가 이 구조를 참조한다.

## 표준 구조
1. **훅 (2~3문장)** — 이 글을 왜 읽어야 하는지. 구체적인 상황/문제.
2. **문제 정의** — 무엇이 어려운지, 어떤 맥락인지.
3. **본론** — 단계별 또는 개념 단위. 각 섹션은 H2.
   - 코드가 있으면 바로 붙이고, 코드 위아래 1~2문장으로 의도/주의점 설명.
4. **흔한 실수 / 함정** (선택) — 내가 겪은 것만.
5. **정리** — bullet 3~5줄. "결론적으로" 같은 군더더기 없이.

## 길이
- 기본 1,500~2,500자.
- 코드 중심 글은 더 짧아도 됨. 설명 중심이면 길어져도 OK.

## 금지
- TL;DR 박스
- "안녕하세요 여러분"류 인사
- "오늘은 ~를 알아보겠습니다" 같은 초등학생 도입부
- 목차 (플랫폼이 자동 생성함)

## AdSense 광고 자연 배치 (CPC 모드일 때 우선 고려)

자동 광고가 끼어들기 좋은 구조를 만들면 CPC 단가가 올라간다. 기본 구조에 다음을 덧붙인다.

### H2 개수와 분포
- **H2를 5~7개로 쪼개라**. H2 ↔ H2 경계가 자동 광고 핵심 슬롯.
- 각 H2 본문은 **최소 200자, 평균 350~500자**. 너무 짧으면 광고 슬롯 안 생기고, 너무 길면 이탈 ↑.
- H2 아래 H3는 1~3개까지. 너무 많으면 광고 위치 분산.

### 도입 hook 직후 슬롯
- hook(2~3문장) 직후에 **빈 줄 + 첫 H2 진입**. 이 사이에 자동 광고가 들어가는데 단가가 가장 높다.
- hook 안에 결론을 미리 던지지 말 것. 결론은 첫 H2 또는 마지막에.

### 본문 중간 시각 요소
- **표(table)·이미지·인용블록**은 광고 자동 배치의 트리거. 비교형 글은 표를 1~2개 꼭 넣기.
- 단, 표 안에 광고가 들어가지 않도록 표 위아래 빈 줄 확보.

### 결론 전 여백
- 마지막 "정리" 섹션 위에 **빈 줄 2줄**. 자동 광고가 결론 직전에 자연스럽게 끼어든다.

### 길이 조정 (CPC 모드)
- 기본 1,500~2,500자 → CPC 모드는 **2,500~4,000자**까지 허용. 광고 슬롯을 더 만들기 위함.
- 단, 분량을 위한 채우기 금지. 비교 표·체크리스트·FAQ 같은 정보 밀도 높은 섹션으로 늘릴 것.
