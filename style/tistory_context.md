# 티스토리 블로그 — 러닝 & 야구

## 니치
- **러닝**: 훈련법, 러닝화 리뷰, 페이스/심박/케이던스, 마라톤 대회 후기, 부상 방지/재활
- **야구**: KBO·MLB 경기 분석, 선수 분석, 구단 이슈, 타격/투구 기술 이야기

## 독자
- 러닝: 서브3/서브4 목표 아마추어, 러닝 입문 6개월~2년차가 대부분
- 야구: 경기를 직접 시청하는 중/상급 팬. 단순 스코어 정리 아닌 **해석**을 원함

## 글 성격
- **경험 기반이 기본**. 내가 뛰어본 대회, 실제 신어본 러닝화, 직관한 경기 이야기를 중심으로.
- 숫자를 아끼지 말 것. 페이스, 심박, OPS, WHIP 같은 지표는 문단 안에 자연스럽게.
- 과장 금지. "역대급", "레전드" 남발하지 않음.

## SEO 관점
- 티스토리는 구글 검색 비중 높음. 제목에 구체 숫자/모델명/대회명 들어가면 유리.
  - 좋은 예: "나이키 알파플라이 3 400km 신어본 후기"
  - 나쁜 예: "알파플라이 후기"

## CPC 친화 주제풀 (`--cpc` 모드 시 우선)

러닝·야구 니치를 유지하면서 CPC 단가가 자연스럽게 올라가는 각도들이다. **인위적 키워드 삽입 금지** — 글 주제와 맥락이 맞을 때만 사용.

### 러닝 → CPC 친화 각도
- **러닝화·장비 비교 리뷰**: "X vs Y", "TOP 5 추천", "가성비/카본화 비교" — 쿠팡파트너스/어필리에이트 + 쇼핑 광고 단가 ↑
- **부상·관절 보호**: 무릎/발목/족저근막염/IT밴드 — 정형외과/도수치료/관절영양제(글루코사민·MSM·콜라겐) CPC ↑↑
- **러닝 보험·실손**: 마라톤 대회 참가 보험, 실손보험 비교
- **GPS 시계·웨어러블**: 가민/코로스/애플워치 비교 — 가전 CPC 중상
- **러닝 다이어트·식단**: 단백질 보충제, 보조식품, 비건 단백질
- **마라톤 대회 준비**: 항공/숙박/원정 — 여행 광고 단가 중상

### 야구 → CPC 친화 각도
- **야구 굿즈·유니폼**: 구단별 유니폼/모자/응원도구 — 쇼핑 광고
- **야구 직관 가이드**: 구장 좌석/주차/맛집 — 지역 광고, 카드 혜택
- **야구 OTT/중계**: 티빙·SPOTV·MLB.tv 구독 비교 — 구독 서비스 CPC ↑
- **야구 게임/장비**: 글러브·배트·스파이크 — 스포츠용품 쇼핑
- **유소년 야구·아카데미**: 학원/레슨 — 교육 CPC ↑↑
- **MLB 진출 선수 + 환전·해외주식**: 류현진/이정후 등 다룰 때 해외계좌·환전 자연 연결 (단, blogger_stocks와 중복 주의)

### 제목 작성 가이드 (CPC 모드)
- "추천", "비교", "TOP", "리뷰", "후기", "가격", "방법" 키워드 1개는 포함
  - 예: "무릎 안 아픈 러닝화 추천 TOP 5 (2026년 발 모양별 가이드)"
  - 예: "마라톤 풀코스 보험 비교 — 실손vs상해 어느 게 유리한가"
  - 예: "잠실야구장 직관 가이드 — 좌석·주차·근처 카드 혜택 정리"

### 절대 피할 것
- 러닝/야구와 무관한 대출/카드/보험 글 (니치 깨짐 + 광고 매칭 떨어짐)
- 단가만 보고 무리한 의료 단정 ("이 영양제가 무릎에 직빵") — YMYL 패널티
