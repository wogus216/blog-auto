# Blogger 블로그 (꾸준함이 재능이다 / consistency.onestepblog.info) — 범용: 러닝·야구·주택(보유)

platform `blogger` (blog_id `6566918690057179781`, config 기본값). 범용 블로그. 미국주식은 `blogger_stocks`, 분양/청약은 `blogger_money`로 분리됨 — 여기는 **러닝·야구·주택(보유/거주 관점)·생활 정보**를 다룬다.

> **필수 선행**: 모든 글은 `style/structure.md`의 **"Blogger 심층 본글 종착지 규약"**을 그대로 따른다(최소 5,000자·이미지 2~4장·FAQ 필수·H1 금지·태그 11개 이하·후크/CTA·내부링크 허브). 아래는 이 블로그 니치 특화만 기술.

## 니치
- **러닝(Blogger판)**: 훈련법·러닝화 리뷰·페이스/심박·대회 후기·부상 방지. 티스토리에도 러닝이 있으므로 **같은 글을 양쪽에 올릴 땐 문체·구조·제목을 전면 교체**(중복 콘텐츠 회피). Blogger판은 영어 독자도 의식해 설명을 더 충분히.
- **야구**: KBO·MLB 경기/선수 분석. 팬심보다 **데이터·분석 관점**.
- **주택(보유/거주 관점)**: 시세 분석, 임대차 실무, 인테리어, 입지 분석. **신규 분양·청약(취득 관점)은 여기 아님 → `blogger_money`로.**
- 생활·정보성: 가전 에러코드, 정책·생활 꿀팁 등 검색 수요 있는 실용 정보.

## 독자
- 러닝: 서브3/서브4 목표 아마추어, 입문 6개월~2년차. + 해외 독자 유입 가능성.
- 야구: 경기를 직접 보는 중/상급 팬, 해석을 원함.
- 주택: 내 집 마련·전세/월세 계약을 앞둔 30~40대. 실용 정보.
- 공통: Google 검색 유입(Blogger는 Google과 직결). **과도한 한국 문화 편향을 줄이고 정보 범용성을 높일 것**(글로벌 플랫폼).

## 글 성격 (필수)
- 데이터·스탯 중심. 추상적 "입지가 좋다"·"잘한다" 금지 → 구체 숫자(단지명·평형·가격·페이스·OPS).
- 제목·소제목은 키워드 중심, 본문은 영어 독자도 따라올 만큼 설명 충분히.
- 1차 출처·실측을 인용(GEO·AI 인용).

## CTA
- **러닝화·러닝 글은 마지막에 allrunabout.com CTA 블록 필수**([[feedback_running_post_cta]]). 고RPM은 allrunabout로 유도.
- 주택 글은 관련 본글 허브 + (분양 연계 시) money 본글 링크.

## 챔피언/내부링크 허브 (어제 인사이트)
- 시즌성+긴 참여 본글 우선(대회 시즌 러닝 가이드, 이사철 주택 체크리스트 등).
- 본글 하단에 관련 본글 2~3개 묶기. 티스토리·네이버 요약글이 여기로 트래픽 펌프.

## SEO (Google 검색 타겟)
- 제목에 **구체 고유명사**(지역·단지·선수·모델명) + 시점/숫자.
  - 좋은 예: "나이키 알파플라이 3 400km 신어본 후기", "잠실엘스 34평 2026년 시세 분석", "손흥민 2025-26 스탯 정리"
  - 나쁜 예: "아파트 시세 올랐다", "손흥민 잘한다", "알파플라이 후기"

## 다른 블로그와의 분리
- **티스토리(러닝/야구)**: 같은 주제라도 문체·구조·제목 전면 교체. Blogger판은 글로벌 범용성·영어 독자 의식.
- **blogger_money**: 신규 분양·청약·부동산 자금은 거기로. 여기는 보유/거주(시세·임대차·인테리어).
- **blogger_stocks**: 미국주식은 거기로.
