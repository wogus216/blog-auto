# CPC 고단가 전략 (공용)

이 파일은 `--cpc` 모드일 때 모든 플랫폼에서 공통 적용되는 작성 원칙이다. 플랫폼별 CPC 친화 주제풀은 각 `{platform}_context.md` 의 "CPC 친화 주제풀" 섹션 참조.

## 큰 원칙

1. **광고주가 검색 광고를 사는 키워드**가 CPC가 높다. 즉:
   - 구매 직전 검색어 ("X 비교", "X 추천", "X 가격", "X 후기")
   - 금액이 큰 의사결정 ("대출", "분양", "보험", "증권사")
   - 전문직 서비스 ("변호사", "세무사", "병원")
2. 단순 정보형 키워드("뜻", "역사", "원리")는 CPC가 낮다.
3. 광고는 콘텐츠의 자연스러운 흐름을 끊지 않을 때 CTR이 가장 높다.

## CPC 친화 글의 구조

### 제목
- **비교/추천/리뷰형 우선**: "X 추천", "X TOP 5", "X vs Y", "X 후기"
- **연도/지역/대상 한정자**: "2026년 30대 보험 추천", "수도권 30평대 분양"
- **구매 의도 키워드 포함**: "가격", "수수료", "조건", "신청 방법"
- **숫자가 들어가면 CTR ↑**: "5가지", "3분 정리", "1억 모은 후기"

### 섹션 구성
- 첫 H2는 **빠른 결론/요약** (광고 없이도 정보 전달이 되어야 이탈 방지)
- 중간 H2들은 **비교/스펙/조건** (광고 사이에 자연스럽게 배치)
- 마지막 H2는 **체크리스트 / 신청 방법 / FAQ** (전환 의도 강화)

### 본문
- 표 (table) 적극 활용. 비교형 콘텐츠는 표가 있어야 CPC 광고 옆에 잘 붙는다.
- 외부 링크는 본문 중간 한 번 + 말미 한 번 정도. 너무 많으면 광고 신뢰도 ↓.
- **YMYL(Your Money Your Life) 주의**: 금융·의료·법률은 단정형 금지, "참고용", "전문가 상담" 문구 한 번씩.

## AdSense 광고 자연 배치

- **광고 자동 배치(Auto ads)**가 잘 동작하려면: H2 사이 본문이 너무 짧으면 안 됨. **H2 하나당 최소 200자 이상**.
- 본문 중 표·코드블록·이미지 사이에는 자동 광고가 들어갈 자리가 잘 생긴다.
- **첫 광고는 hook 직후, 본문 시작 전이 가장 단가가 높다**. 도입 hook은 짧게(2~3문장) 끊고 첫 H2 진입.
- 본문 중간 광고는 **H2 ↔ H2 경계**에 들어간다. 따라서 H2를 5~7개로 쪼개면 광고 노출 면적이 늘어난다.
- 글 말미 광고를 위해 **결론 섹션 위에 빈 줄 + 1줄 이상 여백** 두기 (구글이 자동 광고 끼워 넣음).

## 어필리에이트 / CTA 결합

- CPC 광고 + 어필리에이트 링크는 충돌하지 않는다. 둘 다 깔아도 됨.
- 어필리에이트(쿠팡파트너스 등)는 본문 중간 표 옆 또는 결론 직전 배치.
- CTA는 강요형 금지. "관심 있으면 확인해 보세요" 같은 톤.

## 금지

- 클릭베이트 ("미친 단가", "이거 안 보면 후회") — 단기 CTR은 오르지만 정책 위반 위험.
- 같은 키워드 반복 (키워드 스터핑) — Google 알고리즘 패널티.
- 자기 광고 클릭, 광고 클릭 유도 ("아래 광고도 눌러 주세요") — AdSense 정지 사유.
- 단정형 금융·의료 조언 ("이 상품이 무조건 좋다", "이 약이 가장 효과적이다") — YMYL 패널티.
