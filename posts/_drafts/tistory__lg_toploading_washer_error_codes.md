세탁기가 탈수 도중 멈추고 'UE'가 깜빡인다. 검색하면 LG 드럼세탁기 에러코드만 나온다 — 통돌이는 코드가 다른데.

LG 통돌이(일반 세탁기)는 드럼과 **에러코드 체계가 겹치면서도 다른 부분**이 있다. 특히 PE·tE·CL처럼 통돌이에서만 자주 뜨는 코드가 있고, 같은 UE라도 대응법이 다르다. 드럼 기준으로 조치하면 헛수고할 수 있다.


## 통돌이 vs 드럼 — 에러코드 차이점

| 항목 | 통돌이 | 드럼 |
|------|--------|------|
| UE 주원인 | 빨래 쏠림 (위에서 아래로) | 빨래 쏠림 (앞뒤 균형) |
| PE | 수위 센서 (통돌이 전용) | 거의 안 뜸 |
| IE | 급수 밸브 | 동일 |
| OE | 배수 펌프 | 동일 |
| LE | 모터 과부하 | 동일하지만 빈도 다름 |
| CL | 차일드 락 | 동일 |

**PE(수위 센서)는 통돌이 대표 에러**다. 드럼은 무게 센서 방식이라 PE가 거의 없다.


## PE — 수위 센서 이상 (통돌이 대표 코드)

**증상**: 물이 계속 들어오거나, 적정 수위에서 멈추지 않거나, 아예 작동 안 함.

**원인**: 수위 센서(프레셔 스위치)가 물 높이를 감지하지 못함. 센서 호스 꺾임·막힘이 1순위.

**자가조치**:
1. 전원 끄고 플러그 뽑기
2. 세탁기 뒤쪽 상단의 **수위 센서 호스** 확인 — 가느다란 고무 호스가 꺾이거나 빠져 있으면 바로잡기
3. 호스 끝을 입으로 불어서 막힌 이물질 제거 (물이 역류할 수 있으니 수건 준비)
4. 5분 대기 후 재가동
5. 재발 시 → 수위 센서 교체, **기사 호출**

**비용 참고**: 수위 센서 교체 4~6만 원. 호스만 교체하면 1~2만 원.


## UE — 탈수 중 빨래 쏠림 (가장 흔한 코드)

**증상**: 탈수할 때 세탁기가 심하게 흔들리다가 멈춤.

**원인**: 빨래가 한쪽으로 쏠려 회전 균형이 깨짐. 통돌이는 세로축 회전이라 **무거운 빨래가 바닥에 뭉치면** 바로 UE가 뜬다.

**자가조치**:
1. **빨래를 꺼내서 고르게 다시 넣기** — 이불·패딩 같은 대형 빨래는 단독 세탁
2. 빨래 양이 너무 적어도 UE 발생 — 최소 1/3 이상 넣기
3. 세탁기가 **수평인지 확인** — 바닥이 울퉁불퉁하면 다리 높이 조절
4. 재가동 후 탈수 성공하면 → 정상 (빨래 쏠림이었을 뿐)
5. 빨래 재배치해도 계속 UE → 서스펜션(충격흡수장치) 마모, **기사 호출**

**팁**: 통돌이는 드럼보다 UE가 자주 뜬다. 대형 빨래는 세탁망에 넣으면 쏠림이 줄어든다.


## IE — 급수 안 됨

**증상**: 세탁 시작 후 물이 안 들어오거나 너무 느리게 들어옴.

**원인**: 수도꼭지 잠김, 급수 호스 꺾임, 급수 밸브 막힘.

**자가조치**:
1. **수도꼭지가 열려 있는지 확인** — 의외로 가장 흔한 원인
2. 급수 호스가 꺾이거나 눌려 있으면 풀어주기
3. 급수 호스 연결부의 **거름망(필터)에 이물질** 끼어 있으면 빼서 칫솔로 청소
4. 겨울철이면 **급수 호스 동파** 확인
5. 위 조치 후에도 IE → 급수 밸브(솔레노이드) 교체, **기사 호출**

**비용 참고**: 급수 밸브 교체 5~7만 원.


## OE — 배수 안 됨

**증상**: 세탁은 되는데 물이 안 빠짐. 탈수 전 단계에서 멈춤.

**원인**: 배수 호스 막힘, 배수 펌프 고장, 배수구 이물질.

**자가조치**:
1. **배수 호스** 확인 — 꺾임·눌림·높이(바닥에서 80cm 이하)
2. 세탁기 아래쪽 **배수 필터(거름망)** 열어서 이물질 제거 — 동전·머리카락·실이 가장 흔함
3. 배수구 자체가 막혀 있으면 배수구 청소
4. 배수 펌프에서 **'웅웅' 소리만 나고 물이 안 빠지면** → 펌프 임펠러에 이물질 끼임
5. 재발 시 → 배수 펌프 교체, **기사 호출**

**팁**: 배수 필터는 **한 달에 한 번** 청소가 원칙. 안 하면 OE뿐 아니라 악취 원인도 된다.


## LE — 모터 과부하

**증상**: 세탁기가 돌다가 갑자기 멈춤. 또는 시작 자체가 안 됨.

**원인**: 모터에 과전류가 흘러 보호 회로 작동. 빨래 과다 투입이 1순위.

**자가조치**:
1. **빨래 양 줄이기** — 드럼의 2/3가 최대. 통돌이는 물 위로 빨래가 튀어나오면 과다
2. 전원 끄고 **20분 대기** (모터 냉각)
3. 줄여서 재가동 → 정상이면 과부하였을 뿐
4. 빈 상태에서도 LE → 모터 또는 인버터 보드 고장, **기사 호출**

**비용 참고**: 모터 교체 15~20만 원. 인버터 보드 10~15만 원. 연식 8년 이상이면 교체 vs 신품 비교 필요.


## dE — 도어(뚜껑) 열림

**증상**: 세탁 시작이 안 되거나 작동 중 멈춤.

**원인**: 통돌이 뚜껑이 완전히 닫히지 않음. 또는 도어 스위치 고장.

**자가조치**:
1. **뚜껑을 확실히 닫기** — 빨래가 끼어 있으면 제거
2. 뚜껑 힌지(경첩) 부분에 이물질 확인
3. 닫을 때 **'딸깍' 소리**가 나는지 확인
4. 전원 리셋 후 재발 → 도어 스위치 교체, **기사 호출**

**참고**: 통돌이는 안전상 **뚜껑이 열리면 즉시 정지**하는 구조. 탈수 중 뚜껑 열려고 하면 안 된다(회전축 위험).


## CL — 차일드 락 (에러가 아님)

**증상**: 아무 버튼을 눌러도 반응 없음. 패널에 CL 표시.

**원인**: 아이 잠금(Child Lock)이 켜진 상태. **고장이 아니다.**

**해제 방법**:
- 대부분 모델: **'예약' + '탈수' 버튼 3초 동시 누르기**
- 일부 모델: **'세탁' + '헹굼' 3초 동시 누르기**
- 정확한 조합은 모델마다 다름 — 뚜껑 안쪽 스티커에 표시돼 있다

**팁**: 아이가 있는 집에서 CL은 오히려 유용한 기능. 해제 방법만 알아두면 된다.


## tE — 온도 센서 이상

**증상**: 온수 세탁이 안 되거나, 세탁 중 에러.

**원인**: 수온 감지 센서 오류. 통돌이에서는 온수 세탁 모델에서만 뜬다.

**자가조치**:
1. **냉수 전용으로 세탁** 해보기 — 정상 작동하면 온수 센서 문제 확정
2. 전원 리셋 (플러그 뽑고 5분)
3. 재발 시 → 온도 센서 교체, **기사 호출**

**참고**: 통돌이 대부분은 냉수 세탁이 기본이라 tE가 떠도 냉수 모드로 당장 사용은 가능.


## 에러코드 없이 세탁이 안 될 때

1. **전원이 안 들어옴** — 콘센트 확인, 차단기(두꺼비집) 확인
2. **물이 안 빠지고 멈춤** — 배수 필터 이물질 (OE 코드가 안 뜨는 경우도 있음)
3. **세탁은 되는데 헹굼이 안 됨** — 급수 호스 수압 부족
4. **탈수 시 소음이 심함** — 세탁기 수평 확인 + 운송 볼트 미제거 (신품 설치 시)
5. **곰팡이 냄새** — 통세척 모드(또는 빈 통 + 과탄산소다 1컵) 월 1회 실행

## [FAQ] 자주 묻는 질문

**Q. 통돌이와 드럼세탁기 에러코드가 같은 건가?**
A. IE·OE·UE·LE·dE 등 기본 코드는 동일하다. 하지만 PE(수위 센서)는 통돌이 전용이고, 드럼에만 있는 코드(FE 등)도 있다. 같은 코드라도 자가조치 방법이 다를 수 있다.

**Q. UE가 자주 뜨는데 고장인가?**
A. 대부분 고장이 아니라 빨래 쏠림이다. 이불·패딩 같은 대형 세탁물을 넣을 때 자주 발생한다. 빨래를 재배치해서 해결되면 정상이다. 매번 소량으로도 UE가 뜨면 서스펜션 점검 필요.

**Q. CL이 떴는데 해제가 안 된다?**
A. 모델별로 해제 조합이 다르다. 뚜껑 안쪽 스티커, 또는 LG 고객센터 앱에서 모델 번호 입력하면 정확한 방법이 나온다. 최후 수단은 전원 플러그를 뽑았다 꽂으면 CL이 초기화되는 모델도 있다.

**Q. 통돌이 세탁기 수명은?**
A. 보통 10~15년. 드럼(8~12년)보다 구조가 단순해서 오래 간다. 다만 배수 펌프·수위 센서는 5~7년 차에 교체가 필요할 수 있다.


## 정리: 에러코드별 대응 요약

| 코드 | 부위 | 자가조치 | 기사 필요 |
|------|------|---------|----------|
| PE | 수위 센서 | 센서 호스 확인·뚫기 | 재발 시 |
| UE | 빨래 쏠림 | 빨래 재배치 + 수평 확인 | 매번 뜰 때 |
| IE | 급수 안 됨 | 수도꼭지·호스·거름망 확인 | 재발 시 |
| OE | 배수 안 됨 | 배수 필터·호스 청소 | 재발 시 |
| LE | 모터 과부하 | 빨래 줄이기 + 20분 냉각 | 빈 통에서도 뜰 때 |
| dE | 뚜껑 열림 | 확실히 닫기 | 래치 마모 시 |
| CL | 차일드 락 | 버튼 조합 해제 | 불필요 |
| tE | 온도 센서 | 냉수 모드로 우회 | 온수 필요 시 |

**핵심 — PE는 호스, UE는 빨래, OE는 필터. 통돌이 에러의 70%는 이 세 가지 점검으로 해결된다.**
